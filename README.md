# E-Commerce Sales Performance & Insights Dashboard

This project focuses on analyzing e-commerce sales data to track performance, order status, and customer insights using Microsoft Excel.

## Project Overview
The project uses real transaction data to analyze sales trends, delivery statuses, product categories, and regional performance. It provides clear insights into business sales through an interactive Excel dashboard.

## Files in this Repository
* **`Sales analysis Raw Data.xlsx`**: Raw transactional dataset containing order details, customer information, dates, order status, product categories, quantities, amounts, and shipping locations.
* **`Sales_Performance_Dashboard.xlsx`**: Interactive Excel dashboard summarizing key metrics, order statuses, category breakdowns, and regional performance.

## Tools & Technologies Used
* **Microsoft Excel**: Data cleaning, sorting, filtering, pivot tables, slicers, and interactive dashboard design.

## Key Insights Covered
* **Order Status Analysis**: Tracking counts of delivered (92%), cancelled (3%), returned (3%), and refunded (2%) orders.
* **Sales & Revenue**: Analyzing monthly revenue trends from January to December.
* **Customer Demographics**: Breakdown of sales between Men (36%) and Women (64%), along with age group analysis (Adult, Senior, Teenager).
* **Regional & Channel Performance**: Identifying top-performing states (such as Maharashtra, Karnataka, Uttar Pradesh) and sales channels (like Amazon, Myntra, Flipkart, Ajio).
